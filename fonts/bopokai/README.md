# BopoKai / 波波標楷

以全字庫正楷體（TW-Kai）為基礎，逐字手動修正重心偏移，讓直書排版更整齊。

全字庫的楷體筆畫是手寫墨跡掃描，每個字的視覺重心不一致，直書成段時行氣不穩。波波標楷針對這個問題，用演算法偵測偏移後逐字人工微調，目前已手修 10,251 字。

## 收字原則

波波標楷的目標是做一款實用的免費標楷體，收字以微軟標楷體（DFKai-SB）為基準，再補上主流字型共收且全字庫楷書有 glyph 的字。不含 Ext-B。

| 集合 | 字數 | 說明 |
|------|-----:|------|
| 微軟標楷體 | 21,204 | DFKai-SB 收錄的 CJK 漢字 |
| 主流字型補充 | 598 | 3+ 主流字型共收且全字庫有 glyph |
| 化學元素 | 2 | 鿫 (Og)、鿬 (Ts) |
| 全字庫實收 CJK | 21,506 | 298 CJK Compat 全字庫無 glyph |

最終收錄 **21,506** 個漢字。英數符號（含幾何圖形、雜項符號等）共 1,115 字取自 Noto Serif TC，加上全字庫原有的標點、注音等非漢字 4,978 個，共 26,484 個碼位。
