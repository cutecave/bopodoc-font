# BopoKai / 波波標楷

以全字庫正楷體（TW-Kai）為基礎，逐字手動修正重心偏移，讓直書排版更整齊。

全字庫的楷體筆畫是手寫墨跡掃描，每個字的視覺重心不一致，直書成段時行氣不穩。波波標楷針對這個問題，用演算法偵測偏移後逐字人工微調，目前已手修 10,251 字。

## 收字原則

波波標楷的目標是做一款實用的免費標楷體，收字以教育部正字表為主，加上字嗨補集確保向下相容。

| 集合 | 字數 | 說明 |
|------|-----:|------|
| 正字表 | 29,824 | 教育部《異體字字典》甲乙丙 N 四表 |
| 字嗨 | 13,435 | BpmfZihiKaiStd 收錄的國字 |
| 正字表 ∪ 字嗨 | 29,978 | 重疊 13,281 字，字嗨獨有 154 字（異體補集） |
| 全字庫 ∩ 上列聯集 | 29,978 | 全字庫 100% 涵蓋，缺 0 字 |

最終收錄 **29,978** 個漢字。英數符號取自 Noto Serif TC，加上全字庫原有的標點、注音等共 41,659 個碼位。
