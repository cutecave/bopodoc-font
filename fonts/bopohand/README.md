# BopoHand / 波波手寫

改作自[辰宇落雁體 2.0 細體](https://github.com/Chenyu-otf/chenyuluoyan_thin)（王立宇、劉韋辰）。

字形沒有修改，只有改名。辰宇落雁體以 SIL Open Font License 1.1 授權，並把「辰宇落雁」「Chenyuluoyan」定為保留名稱，改作的字型不能沿用，所以改名為波波手寫，讓波波注音可以把它切片放進線上編輯器使用。

原版字型請到原作者的 GitHub 下載。

## 搭配注音

在波波注音選用波波手寫，注音會自動換成同一套筆跡的「波波手寫純注音」。
