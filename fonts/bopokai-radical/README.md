# BopoKaiRadical / 波波標楷部首

配合波波標楷製作的部首字型。每個字只保留部首筆畫，疊在波波標楷上使用，可以用顏色強調每個字的部首位置。

透過 IDS（表意文字描述序列）拆字分析找出部首位置，再從全字庫正楷體擷取對應筆畫。程式自動拆解後，再經手工逐字校對修正。

## 收字

與波波標楷相同，共 21,506 個漢字。

## 使用方式

將 BopoKaiRadical 疊在 BopoKai 上方，設定不同顏色即可凸顯部首。適合用於國語文教學、生字簿等場景。
